## Системные вызовы, используемые в заданиях
| Вызов      | Заголовок   | Описание                        |
|------------|-------------|---------------------------------|
| `getpid()` | `unistd.h`  | PID текущего процесса           |
| `getppid()`| `unistd.h`  | PID родительского процесса      |
| `open()`   | `fcntl.h`   | Открытие файла                  |
| `read()`   | `unistd.h`  | Чтение из файлового дескриптора |
| `write()`  | `unistd.h`  | Запись в файловый дескриптор    |
| `close()`  | `unistd.h`  | Закрытие файлового дескриптора  |
