## Задания

### Задание 1 — Портирование файловых операций
Демонстрирует замену Windows API на кросс-платформенный пакет `os`:

| Windows API    | Go (os package)           |
|----------------|---------------------------|
| `CreateFile()` | `os.OpenFile()`           |
| `ReadFile()`   | `file.Read()` / `os.ReadFile()` |
| `CloseHandle()`| `file.Close()` + `defer` |

### Задание 2 — Безопасная работа с указателями
Реализует рекомендации лекции применительно к Go:

| Правило (лекция)                  | Реализация в Go                        |
|-----------------------------------|----------------------------------------|
| Инициализация в NULL              | `var p *int = nil`                     |
| Проверка перед использованием     | `if p != nil { ... }`                  |
| Очистка после освобождения        | `p = nil` после использования          |
| Современный язык с управлением памятью | GC + отсутствие ручного `free()`  |
| Статический анализ                | `go vet`                               |
| Динамическое тестирование         | `go run -race`                         |

### Задание 3 — Параллельные вычисления
Суммирование массива из 100 млн элементов двумя способами:

| Способ                  | Механизм                          | Аналог в C         |
|-------------------------|-----------------------------------|--------------------|
| Вариант 1               | `goroutine` + `channel`           | `pthread` + pipe   |
| Вариант 2               | `goroutine` + `sync.WaitGroup`    | `pthread_join`     |
